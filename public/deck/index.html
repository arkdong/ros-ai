Responsible design

An open-source workspace designed for researcher control and review

01

Control
data access

Keep source files read-only by default. Ask permission before changing files or sending data outside the workspace.

02

Bound
AI actions

Set clear permissions and resource limits. Run code in isolation and let researchers stop work at any time.

03

Keep evidence
inspectable

Keep inputs, code and results together. Make errors visible and check conclusions against the evidence.
