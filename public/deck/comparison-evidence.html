Each unchanged program reproduced 4/4 reference metrics: 41.4 percentage points between the largest and smallest covered groups, 20.3 percentage points between the largest group's adopter-turnover and enterprise-adoption shares, two negative-difference groups, and six aggregate size groups. Each also produced a six-row table, a plot and a short conclusion.

It covers Dutch enterprises with at least ten persons employed in sectors C–N and Q, with provisional 2024 estimates. The rows represent aggregate groups, not six firms. Turnover and enterprise percentages have different denominators; no causal effect is established. CBS source.

Kimi: No interpretation text returned. The draft is not assessable. The adapter did not retain that response's token usage or charge, so the table reports only the known proposal usage and preserves the failed call's $0.5092736 reservation.

These are nonblind coding-assistant rubric scores, not an independent human evaluation. All configurations used a 1,400-token cap per response. GPT-5.4 used reasoning effort none; Nebius used provider reasoning defaults. Output-token counts include reasoning, leaving different amounts of space for visible writing.

Timing and cost definitions

API time sums app-observed elapsed time around both provider completion calls, including waiting for Kimi's failed response. It excludes catalogue admission, local queueing, review/recovery pauses and Python execution. Python time runs from native execution start to saved completion, including runtime setup. Each value is one observation; no percentile, average or significance claim is made.

$0.04710595 is the sum of known token-price estimates, with one additional Kimi charge unknown. The full retained conservative amount is $8.0336512 within the $40 total cap. Reservations are not bills, and remaining headroom was not reused. New paid admission was disabled after the six requests.

Prices were checked on the measurement date: GPT-5.4 $2.50 input / $15 output per million tokens on the official model page; authenticated Nebius catalogue rates were Nemotron $1 / $3 and Kimi $0.95 / $4 per million. Estimates use uncached published rates, not an account invoice.
