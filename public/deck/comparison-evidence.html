Measurable model advantage

Baseline: We compared our open-model choice, Nebius-hosted Nemotron 3 Ultra, against closed-model OpenAI GPT-5.4, with Kimi K2.7 Code as an additional configuration. All used the same captured CBS evidence, task and prompt template: propose Python, execute the original code, then interpret the actual outputs. Model inputs for interpretation contain each program's own outputs.

What we measured: correctness against four fixed numerical answers, app-observed API latency, estimated token cost per request, and draft quality on a previously fixed eight-point rubric (evidence fidelity, numerical correctness, caveats and usefulness; 0–2 each).

Observed advantage: On the successful code-proposal request, Nemotron cost $0.005078 versus GPT's $0.012295 (58.7% less) and took 2.976 versus 6.681 seconds (55.5% less time). Both original programs passed 4/4 numerical checks without edits. Kimi also passed 4/4 at $0.00519645 and 3.938 seconds.

Tradeoff: GPT returned a complete interpretation scoring 8/8; Nemotron scored 5/8 and stopped at its response cap. Kimi returned no interpretation text, so its quality and final charge are unknown. The cost/latency advantage above is specifically for successful code generation. This single trial does not establish better overall research quality. Timing and cost definitions

API time sums app-observed elapsed time around both provider completion calls, including waiting for Kimi's failed response. It excludes catalogue admission, local queueing, review/recovery pauses and Python execution. Python time runs from native execution start to saved completion, including runtime setup. Each value is one observation; no percentile, average or significance claim is made.

$0.04710595 is the sum of known token-price estimates, with one additional Kimi charge unknown. The full retained conservative amount is $8.0336512 within the $40 total cap. Reservations are not bills, and remaining headroom was not reused. New paid admission was disabled after the six requests.

Prices were checked on the measurement date: GPT-5.4 $2.50 input / $15 output per million tokens on the official model page; authenticated Nebius catalogue rates were Nemotron $1 / $3 and Kimi $0.95 / $4 per million. Estimates use uncached published rates, not an account invoice.
