## Enforcement and remaining scope limits

The local runner interprets a closed numerical Python subset using a trusted AST interpreter; user code is never passed to `exec`/`eval`. It does not offer imports, object attributes, loops, arbitrary files, network, shell or package installation. It has strict input/output limits, a scrubbed child environment, process timeout, and recorded resource-limit outcomes. It is **not general Python and not an OS sandbox**; Python/interpreter vulnerabilities and guaranteed macOS memory isolation are outside its claimed boundary.

The local starter is a descriptive-analysis recipe, not free-form model reasoning. Arbitrary experiments/dependencies, automated permission review and Full access are unavailable. Worker output is captured at completion per activity, not streamed continuously within a Python computation. Auto Research operates on already previewed actions, with no autonomous new structure or synthesis. Browser closure leaves the local process running; process/laptop shutdown interrupts local work. An orphaned child after abrupt parent death is subject to its resource limits, without guaranteed immediate termination or recovered uncommitted output.

No Nebius Jobs/Endpoints, remote storage, callback receiver, cloud control plane, full Codex/DeepSeek runtime, accounts or hosted deployment was provisioned. The cloud work is documentation review only; specific access/quotas/regional runtime prices remain unverified. No event entry was submitted.
