**Is the weather really worse at the weekend?** Everyone has an opinion. Here we check it with one year of real measurements, without writing any code ourselves.

**How to work:** ask in plain words. ros.ai's assistant writes the Python, it runs in a sandbox on this computer, and every chart, number and attempt stays on the canvas with the code that made it.

**What a good answer contains**
- the number of days behind every average;
- both the average and the median, because a few very wet days can pull an average up;
- a chart someone without a statistics course can read;
- one sentence on what the numbers do not show.
