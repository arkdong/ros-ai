This canvas follows one question from the first search to a draft article. Walk it from left to right.

1. **Question.** What we want to know and for whom.
2. **Agent.** Claude Code took the question on, planned three search directions and waited for approval.
3. **Search and Result.** Each direction is a Tavily search. The Result note next to it summarises what came back and cites every page.
4. **Findings.** Claims worth keeping, each quoting its page word for word.
5. **Data, Code and Notebook.** The CBS table as a dataset, the analysis as Python you can run, and a notebook for exploring further.
6. **Draft article.** A report built from the findings and the calculated figures.

**What is recorded and what is live.** The searches, findings and draft were prepared for this demo from the pages and data captured on 23 September 2026, so nothing here costs money or needs a key. Every block is real and editable. With an Anthropic key on Model and a Tavily key on Plugins, select the Question and ask Claude Code to research it: a live Agent block grows next to this one. With Docker running, **Run** the Code block or a Notebook cell to calculate again.
