# ros.ai

The words the product uses, for people and agents working on this repository. On screen and in docs, use these. Where the code still has an older word, the entry says so.

## Language

**Canvas** (also **map**, for the screen):
One project's blocks, groups and links, laid out by the person. There is one canvas per project.

**Block**:
One thing on the canvas, named for how you work with it: Text, Code, Notebook, Data, File, Paper, Notion, Google Drive, Post, Metrics, Dashboard, Map, App, Agent or Web. Older code and records say *node* or *note*.

**Label**:
The word on a Text block that says what it means to the project: question, task, finding, decision, draft, or the person's own word.

**Group**:
The only thing that contains blocks. Groups can hold Groups. Being in a Group never runs or schedules anything.

**Link**:
One word between two blocks, such as *supports* or *uses data from*. It says how they relate and never runs, schedules or imports anything. Older code says *relationship*.

**ROS**:
ros.ai's own agent, and the bar at the bottom of the canvas where the person directs any agent. Hosted ROS runs on ros.ai cloud; ROS on this computer is the downloaded ros-nemotron model.

**Agent**:
Anything that does work on the canvas with ros.ai's tools: ROS, Claude Code, Codex, Gemini CLI, Goose, OpenCode, an API model in ros.ai's own loop, or the person's own agent connected through MCP.

**Thread**:
One conversation in a project, with its own history and agent session. A project holds many, and two can run at once.

**Turn**:
One message to an agent and everything the agent did in answer.

**Proposal**:
A change an agent wants to make. The server checks it, and it lands or waits according to the permission mode. A model's answer is never itself an action.

**Permission mode**:
The project's one setting for what lands without the person's OK: Ask every time, Approve for me, or Full access.

**Saved output** (in code, *artifact*):
Something a run or an edit produced: a table, figure, metric, report or captured source. It is kept as a version and never rewritten.

**Plugin**:
An outside app every agent can use, such as Notion, Google Drive or GitHub. A read runs straight away; a write waits for the person.

**Skill**:
A saved way of working that an agent follows when a task matches, in the Agent Skills format.

**Project folder**:
The folder on the person's computer that holds a project's blocks as ordinary files.

**Data folder**:
Where ros.ai keeps its own records: the database, saved outputs, keys and sign-ins.
