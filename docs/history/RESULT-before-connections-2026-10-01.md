## What works

Select blocks on the canvas, enter a title and choose Group. Groups contain notes, Actions, datasets, figures, code and reports, support deliberate nesting, and expose Move/Ungroup in Details. Expanded Groups are enclosing frames; collapsed Groups show the count, current work states and up to three explicitly selected exact-version highlights. A highlight opens its originating captured artifact. Only Groups expand; research blocks open their content. Existing container identities, overview text, legacy research roles and immutable outputs survive conversion. Conversion and moves preserve effective model choices; later resetting inheritance is explicit. Grouping grants no authority or new resources.

Each research block has one primary content preview with purpose/current work state. Earlier successful output remains distinguishable from failed, interrupted or active work. Details → Results exposes all saved versions, including captured code/data/logs. Relationships retain original endpoints; collapsing projects visible connections and inspection lists their contributions. Layout, expansion and viewer preferences remain outside content undo history and preserve redo.

Assistant submission saves a pending local admission record before sending. Network errors, deadlines and unknown outcomes leave a persistent conversation warning, retained draft and read-only refresh/setup actions. Returned admitted state is applied immediately; polling cannot starve visible completion by overlapping requests. Saved-record replies explicitly say no model inference and show the exact configured connection/authorization blocker. Existing progress/Stop and durable interrupted turns remain. A stopped project also records a visible failed submission.

The originally reported silent response **was not reproduced**: the first actual browser submission in a fresh project completed in saved-record mode. Consequently there is no proven original root cause or claim that its specific cause was repaired. The known admission/polling/failure-display gaps above were addressed and a real local-server outage was exercised: uncertainty survived reload, no automatic retry occurred, and deliberate continuation completed visibly.

Connection setup distinguishes installed, signed in, configured, authorized and available. Codex uses its own native app-server authentication, separately from direct API models and Python. Its adapter implements bounded selected-context tools, captured streaming/progress/output, cancellation, narrow proposals, report review, durable uncertainty and cumulative grant reservations. Only explicitly captured block/artifact versions enter its scope; grouping and links do not import descendants or neighbors. Accepted effects pass store validation and approval/resource policies. Credentials remain server-side; Codex credentials are not copied. A standalone MCP transport and embedded Claude adapter are future consumers of this seam, not implemented services.

Datasets have pagination, all-column search, column filters, numeric/text sorting, column visibility and compact types/missing summaries. All captured rows remain accessible. A cleaned-copy preview supports fixed transformations and records before/after results; saving creates an immutable derived dataset block with source ID/hash and operations. The original capture and local file remain unchanged. View filters never silently become data changes.

Figures support 50–400% viewing, direct SVG download and navigation to their producing attempt/exact inputs. Caption/report-width changes save a distinct presentation-derived version with unchanged SVG. Retained code can prepare a separate Action with exact figure/dataset selections for reviewed recomputation; preparing does not execute. Old SVGs remain saved images and supply no inferred observations.

Ordinary projects can create/edit reports with text, inline saved figures/tables, captions and exact evidence. Evidence opens the captured version and provenance; newer versions show a notice without replacing the selection. Manual report edits create new immutable versions and undoable block changes. Agent revisions remain pending until specific acceptance. Claim labels distinguish source, model, measured result and user interpretation. Markdown and standalone HTML exports preserve selected evidence, original raw CSV/JSON, SVG, IDs, hashes and captured metadata without external content requests. Notebook, Office and database engines remain future work.
